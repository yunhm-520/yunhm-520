## 📂 项目一览

### 🖱️ [云工坊 · yun-gongfang](https://github.com/yunhm-520/yun-gongfang)

**主力项目。** 一组纯前端、零依赖、打开即用的图片与鼠标指针制作工具，所有处理都在浏览器本地完成，不上传图片。

- 🖼️ **图片工坊** —— 调整、滤镜、缩放、裁剪、马赛克、画笔、文字水印
- ✂️ **抠图工坊** —— 网格切分 + 魔棒抠图，一键拆出多个透明元素
- 🖱️ **指针工坊 Pro** —— 17 角色独立作品、AI 超分、自动动画、实景试戴，导出标准 CUR / ANI / INF 皮肤包
- 📖 附[完整图文说明书](https://github.com/yunhm-520/yun-gongfang/blob/main/%E6%8C%87%E9%92%88%E5%B7%A5%E5%9D%8A_%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E%E4%B9%A6.html)

技术栈：原生 HTML / CSS / JavaScript、Canvas ImageData、WebGPU（WebSR）

### 🎓 [学生管理系统 · xuesheng](https://github.com/yunhm-520/xuesheng)

Java 学习项目，用 Swing 做图形界面管理学生信息。仓库里有两个独立版本：内存版用 HashMap 存数据，JDBC 版用 jtds 连 SQL Server。包含添加、删除、修改、查询和登录界面。

技术栈：Java、Swing、JDBC、SQL Server

### 🌸 [原神主题页面 · io](https://github.com/yunhm-520/io)

2022 年的前端练习，一个原神主题的静态页面，配置过 GitHub Pages 自动部署。属于早期作品，详见仓库 README。

技术栈：HTML、CSS、jQuery
